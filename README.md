# Password Strength Checker

A responsive Password Strength Checker built using HTML, CSS, and JavaScript. This project evaluates password security based on common cybersecurity best practices such as password length, uppercase and lowercase letters, numbers, symbols, and common password detection.

## Features

* Real-time password strength analysis
* Password visibility toggle
* Responsive modern UI
* Security feedback and improvement tips
* Color-coded strength meter
* Common password detection

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Purpose

This project was created to strengthen my front-end development and cybersecurity skills while building something practical and recruiter-friendly for my portfolio.
